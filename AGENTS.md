## Strict Code Commenting Rules (Mandatory for all AI Agents)

1. **Language**: Code comments (in SQL, TypeScript, JavaScript, CSS, Shell, config, and test files) MUST ALWAYS be in English. NEVER write code comments in Indonesian.
2. **No Patterns or Decorative Banners**: NEVER use decorative, boxed, or patterned comments. Absolutely NO repeated characters like `===`, `---`, `***`, `###`, ASCII borders, or divider lines.
3. **Concise and Minimal**: Comments must be short (single-line wherever possible), meaningful, and explain "why", not "what". Avoid verbose multi-line comment blocks or stating the obvious.
4. **Header Files**: File headers must be either omitted or at most 1 concise single line. No decorative multi-line header blocks.
