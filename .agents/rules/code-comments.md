# Code Commenting Guidelines

1. **English Only**: All code comments in SQL, TypeScript, JavaScript, CSS, Shell, config, and test files must be in English. Never use Indonesian in code comments.
2. **No Patterns or Decorative Separators**: Never use patterned or decorative comments (no lines with `===`, `---`, `***`, ASCII banners, or divider boxes).
3. **Concise and Meaningful**: Keep comments short (single-line wherever possible). Explain rationale/intent ("why"), not obvious operations ("what").
4. **Header Files**: File headers must be either omitted or at most 1 concise line. No multi-line decorative header blocks.
